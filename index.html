تنويه مهم لحماية بياناتك

        

        

          تم تطوير هذا البرنامج بالذكاء الاصطناعي ويعمل على منصّات سحابية مجانية.

          لحماية بياناتك بشكل دائم، يُنصح بأخذ نسخة احتياطية يدوياً عند انتهاء العمل.
        

        
🕛 علماً أن التطبيق يأخذ نسخة احتياطية تلقائية يومياً الساعة 12:00 ليلاً

      


      
      

        
كيف يعمل التطبيق؟

        
    
          
  1. اختر طريقة التشغيل: أنشئ حسابك السحابي مباشرةً بالبريد الإلكتروني وأكّده عبر الرسالة للعمل على عدة أجهزة معزولاً بالكامل (مع التنويه أن الحسابات غير المستخدمة لمدة 90 يوماً متواصلة تُحذف لتوفير المساحة ما لم تكن مثبّتة)، أو استخدم الحساب المجاني الأوفلاين مباشرةً على جهازك (حتى 25 زبوناً).
    2. 
          
  2. سجّل الديون والدفعات: اضغط «عملية جديدة» أو افتح ملف أي زبون لتسجيل دين أو دفعة بالدولار أو الليرة السورية مع الملاحظة.
    3. 
          
  3. أرشفة ذكية تلقائية: بمجرد تسديد الزبون كامل حسابه تُطوى الدورة تلقائياً في درج الأرشيف ليبقى الكشف الجديد نظيفاً وواضحاً.
    4. 
          
  4. المشاركة والمطابقة: أرسل للزبون إشعاراً فورياً عبر واتساب أو كشف حساب PDF (حالي أو شامل مع الأرشيف) بضغطة زر واحدة حتى بدون إنترنت.
    5. 
        

      


      
      

        
ملخص جميع ميزات التطبيق

        

          

            1. إدارة العملتين والأرشيف التلقائي
            دعم الدولار ($) والليرة السورية (ل.س) أو العملتين معاً بحسابات منفصلة، مع نقل الدورات المسدّدة للأرشيف وإبقاء أي رصيد مفتوح ظاهراً حتى تسديده.
          

          

            2. كشوفات حساب PDF احترافية (تعمل أوفلاين)
            تصدير كشف حالي أو شامل مع الأرشيف جاهز للطباعة بلون خفيف، مع شعار المحل وهواتفه، خيار كود «شام كاش» القابل للنسخ، ومشاركة الملف باسم العميل والتاريخ فقط، ومُخزّن محلياً للعمل بدون إنترنت.
          

          

            3. رسائل واتساب مخصّصة بالكامل
            اختيار واتساب عادي أو أعمال، والتحكم بجميع أجزاء الرسالة (التحية، آخر عملية، الملخص، شام كاش، العنوان والهواتف، ملاحظة مخصصة) مع معاينة فورية.
          

          

            4. العمل الكامل بدون شبكة (أوفلاين أولاً)
            عرض وتعديل وتسجيل العمليات بدون إنترنت مع إظهار تاريخ وساعة آخر تحديث عند الانقطاع، وإخفائهما تلقائياً عند الاتصال والمزامنة.
          

          

            5. حماية الأسماء ومنع التكرار
            منع تثبيت الأسماء المتطابقة أو المتشابهة إملائياً ومنع انتقال رقم الهاتف أو خلط الحركات من الأسماء القديمة، وإظهار الأسماء المتطابقة المضافة أوفلاين من جهازين معاً بعلامة واضحة لتعديل أحدها بدون إضافة كلمات بجانب الاسم.
          

          

            6. النسخ الاحتياطي التلقائي واليدوي
            نسخ تلقائي يومي على الجهاز الساعة 12:00 ليلاً، مع إمكانية الحفظ والمشاركة بصيغة JSON أو Excel (CSV) والاستعادة بضغطة زر.
          

          

            7. الحماية وتخصيص الواجهة
            قفل التطبيق بالرمز السري (PIN) أو البصمة، الوضع الليلي والنهاري والتلقائي حسب الجهاز، خيار إخفاء وإظهار أزرار التصنيفات في الشاشة الرئيسية، وتأكيد الخروج بالرجوع مرتين.
          

          

            8. حسابات سحابية مستقلة بالإيميل ومزامنة عدة أجهزة
            إنشاء حساب مستقل لأي مستخدم بالبريد الإلكتروني مع تأكيد عبر رسالة بريدية، عزل كامل للبيانات بين الحسابات، إمكانية فتح الحساب على عدة أجهزة معاً، وإضافة موظفين مع قفل الجهاز الواحد وزر «إخراج من الجهاز».
          

          

            9. الحساب المجاني الأوفلاين والترحيل للسحابة
            يعمل مجاناً بالكامل بدون إنترنت حتى 25 زبوناً، وعند تسجيل الدخول بحساب سحابي لأول مرة يعرض ترحيل الحركات تلقائياً في حال وجود بيانات محفوظة.
          

          

            10. سجل التدقيق والمتابعة (آخر 14 يوماً)
            سجل تلقائي محمي يوثّق كل تعديل أو حذف أو تغيير موعد تسديد مع التفاصيل قبل وبعد واسم المستخدم والتوقيت، ويتجدد تلقائياً كل 14 يوماً لتوفير المساحة.
          

          

            11. تذكير بالديون المتأخرة ومواعيد التسديد
            تحديد موعد تسديد لكل زبون مع تنبيه تلقائي للديون المتأخرة والمستحقة اليوم وزر تذكير فوري عبر واتساب.
